jlceda-pcb-ai-workflow
详细系统运行流程 · 各节点对应的专业设计规则

依据实际代码与数据生成（tools/gen_flow_doc.py）｜规范数值抓取于 2026-10-30，国内站口径（jlc.com）｜范围：需求 → 导出 Gerber + BOM + 坐标 → 封存

一句话：Agent 负责设计与判断，脚本只负责“在声明范围内独立复核”，用户用编号答复过 5 道门禁，最后封存成带哈希的发布包。 全程不上传、不下单；缺工艺声明、缺证据一律 BLOCKED，不猜、不默认通过。 本文共收录 29 条 PCB 制板工艺规则、20 条 SMT 设计规则（声明贴片才启用）、24 条 BOM/坐标规则，每条都带官方原文片段与来源。

2　门禁与失效机制（workflow.py，dialogue 模式）

门禁确认什么汇报最低内容
G1 原理图原理图可进入 PCBERC 结果、未连接引脚清单、电源/复位/时钟/接口逐项观察
G2 库/封装核心器件引脚 / 封装与 datasheet 一致每个核心器件的对照结论、替代料说明
G3 布局分区、关键回路、天线 / 板边 / 孔位分区、已知例外
G4 PCBDRC 清零、规则可信drc_check 结果、规则预设名、逐层读图观察
G5 导出放行Gerber / BOM / 坐标可进入封存gerber_guard 全量输出（含“不评估”清单）、成本触发项、sha256
机制
  • confirm 必须带 --user-reply（用户原话），空的直接 BLOCKED——Agent 不得代答。选 2(修改后重审)/3(暂停) 会被记录，但门禁仍是 PENDING。
  • 选 1(通过) 必须 --bind 被确认的文件，记录其 sha256。
  • 按顺序：前序不是 CONFIRMED，后序无法确认。
  • 自动失效：被绑定文件一变，该门禁及其后全部变 STALE，必须重新确认。
  • CONFIRMED 只表示“用户在对话里确认过那个版本”，不是技术通过，也不是电子签名。

P1 设计规则 PCB EDA：读/写

给 EDA 的 DRC 配一把“不低于嘉立创工艺”的尺子。DRC 只按当前规则查，规则被设松它照样放行，所以这一步是兜底。

输入

process.json、EDA 当前规则配置

执行者

Agent → EDA；rules_check 离线

产出

规则快照 + 规则门禁报告

失败回退

规则低于极限 → 改规则（须有工艺依据并留痕）后重跑

做什么

  • 读官方预设：eda.pcb_Drc.getAllRuleConfigurations(true)（7 套 JLCPCB Capability，已存 data/rule-presets）
  • 按层数选对应预设作基线；预设 = 建议值，工艺页 = 极限值
  • 建网络类（电源 / 高速 / 普通）、差分对，线宽 ≥ 预设最小值；写回 overwriteCurrentRuleConfiguration
  • 取回当前规则 → rules_check.py 离线核对：规则里的下限当作“实测值”，按三档对照工艺

命令 / 入口

rules_check.py --dump-js（打印取规则的单句 JS）→ bridge_client exec → rules_check.py --config rules.json --process process.json

对应的设计规则 / 约束

  • 自动 PCB.TRACE.WIDTH_MIN 线宽下限
  • 自动 PCB.TRACE.SPACE_MIN 线-线间距
  • 自动 PCB.PAD.TO_TRACK 焊盘-走线间距
  • 自动 PCB.DRILL.PLATED_MIN 过孔内 / 外径下限、孔到孔
  • 自动 PCB.VIA.OUTER_MIN
  • 自动 PCB.VIA.HOLE_EDGE_GAP
  • 自动 PCB.MASK.BRIDGE_1OZ_COLOR 阻焊桥(焊盘-焊盘间距)、阻焊单边扩展
  • 自动 PCB.MASK.EXPANSION_MIN
  • 自动 PCB.EDGE.ROUTED 走线 / 焊盘到板边（锣边 或 V 割）
  • 自动 PCB.EDGE.VCUT

GB.OUTLINE.CLOSED / EMPTYBLOCK板框非空且闭合（端点度数奇偶判定），并给出外接尺寸
GB.DRILL.VIA_SUBSETBLOCK*_Via.DRL 必须是 PTH 钻孔的子集（按孔径计数）
GB.COPPER.EMPTYWARN铜层图形操作数过少（启发式阈值取自 data，不是官方规范）
GB.TRACK.NONEWARN所有铜层都没有走线：疑似未布线或导出遗漏，不得视为线宽合格
gerber_guard 明确不评估（需 EDA API 或几何运算，报告每次逐项列出，不得视为通过）：线距、焊盘到线距离、阻焊桥、丝印字高、丝印到焊盘间隙、铜到板边距离、过孔外径 / 孔环 / 孔边距。这些按决定交给 EDA 自身 DRC。

8　边界：明确不做什么

事项为什么 / 怎么办
下单、上传到任何第三方红线。bridge_client 发送前拦截 placePcbOrder / placeSmtComponentsOrder / placeComponentsOrder；release 只在本地封存
线距 / 焊盘距 / 阻焊桥 / 孔环 / 板边的设计实际值检查按决定交给 EDA 自身 DRC；本 skill 保证“DRC 的尺子不低于嘉立创工艺”
验证 C 编号与器件是否对应不联网无法验证；官方：填了编号以编号为准，错误编号比缺少更危险，以嘉立创下单页匹配结果为准

xls / xlsx不解析 → BLOCKED，要求另存 CSV（官方只读首个工作表前 12 列）
