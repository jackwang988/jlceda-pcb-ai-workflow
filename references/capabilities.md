# 能力边界

通用的是阶段、数据接口、检查方法与证据门禁。具体电路、封装、电流、阻抗、适用标准必须来自项目与原厂资料。

| 能力 | 方式 | 边界 |
|---|---|---|
| 工程读写 | 经 Bridge 调 `eda.*`（分批、save、回读对账） | 依赖用户已配好的通道与 EDA 版本；BETA 接口先 `typeof`；`getPdf/Svg/PngFile` 会卡死 EDA，默认拦截 |
| 原理图 | Agent 设计并经 API 放置/连线；`sch_Drc.check` | 不提供“需求→正确电路”的自动综合；ERC 通过≠电路正确 |
| 选型 | 对照 datasheet 核引脚/封装/关键值 | 无自动查 EOL/NRND、库存价格；**不联网验证 C 编号与器件对应** |
| 设计规则 | 读官方预设→建网络类→写回；`rules_check.py` 离线核对规则不低于工艺 | 不做阻抗求解；检查的是**规则值**不是设计实测值 |
| 几何检查（线距/焊盘距/阻焊桥/孔环/板边） | **EDA 自身 DRC** | 本 skill 不重复实现；规则放宽则 DRC 一并放宽，故有 `rules_check` 兜底 |
| 布局/布线 | 人工 + `autoLayout/autoRouting`（若存在） | 自动结果仅作候选；900s 硬上限 |
| 原生 DRC | `drc_check.py`（verbose，只读） | 范围=已启用规则 |
| Gerber | `export_gerber.py` 导出；`gerber_guard.py` 独立复核 | 只复核文件能反推的项；导出≠内容正确 |
| BOM/坐标 | `export_bom_cpl.py` 导出并规范化；`bom_cpl_guard.py` 复核 | 格式类硬规则全自动；**不判断极性/旋转对错**，不核对 C 编号 |
| 流程门禁 | `workflow.py`（dialogue，按序、绑定文件哈希、自动失效） | 确认≠技术通过，也不是电子签名 |
| 封存 | `release.py`（重新复核+哈希清单，仅本地） | 不上传、不下单 |
| 规范维护 | `spec_drift.py` 比对官方页面数字（只报告） | JS 渲染页抓不到内容时报 BLOCKED，不据此说“没漂移”；`jlc-pcb.com` 站点对爬取返回 403，需手动抽查 |
| **不做** | 下单、上传、CAM/DFM 外部复核、样机、ECO、SI/EMC/热/功耗、原理图/PCB 源文件打包 | 超出范围 |

## 放行边界语言

- “退出码 0”= 声明范围内无阻断，不是“合格”。
- “Gerber/BOM 文件存在”不等于“内容正确”；“DRC 通过”不等于“满足嘉立创工艺”。
- 本 skill 的 PASS 不能替代嘉立创自身的下单审核与工程师判断。
